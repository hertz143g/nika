# Ника

Production-ready адаптивный лендинг персонального ИИ-репетитора.

## Запуск

Проект не требует сборки или зависимостей. Откройте `index.html` напрямую либо запустите любой статический HTTP-сервер в корне проекта.

## Структура

- `index.html` — семантическая разметка всех секций, формы, таблицы и FAQ.
- `styles.css` — дизайн-токены, desktop/mobile layout и responsive breakpoints.
- `script.js` — плавная навигация, accordion и клиентская валидация формы.
- `assets/illustrations` — отдельные оригинальные иллюстрации из предоставленного дизайна.

PDF-макеты и полностраничные скриншоты не используются в интерфейсе сайта.
