# Ника

Адаптивная веб-версия лендинга по предоставленным десктопному и мобильному макетам.

Откройте `index.html` напрямую в браузере или запустите любой статический веб-сервер из этой папки.

- Десктопный эталон используется при ширине окна больше 640 px.
- Мобильная композиция используется при ширине окна до 640 px и точно совпадает с макетом на ширине 390 px.
